# ใบเช็กลิสต์ยืมของ ห้องผ่าตัด

แอปบนมือถือ/คอม ใช้ร่วมกันหลายเครื่องแบบสด ไม่มีข้อมูลผู้ป่วย (ไม่มี HN)

- **หน้าแอป:** GitHub Pages (`index.html`) — แก้ไฟล์แล้ว Commit ทุกเครื่องอัปเดตเอง
- **ที่เก็บข้อมูลกลาง:** Supabase (ฟรี) — ตั้งค่าครั้งเดียว ด้านล่าง
- **ใบ A4 แบบกระดาษ:** โฟลเดอร์ `forms/`

## ตั้งค่าครั้งแรก (ทำครั้งเดียว ประมาณ 10 นาที)

### 1) สร้างฐานข้อมูล Supabase
1. เปิด https://supabase.com → **Start your project** → **Continue with GitHub**
2. กด **New project** แล้วกรอก: Name = `or-checklist`, Database Password = ตั้งรหัสแล้วจดไว้, Region = **Southeast Asia (Singapore)**, Plan = **Free** → **Create new project** (รอประมาณ 2 นาที)
3. เมนูซ้าย **SQL Editor** → **New query**
4. เปิดไฟล์ `supabase/setup.sql` ใน GitHub → กดปุ่ม **Copy raw file** → วางในช่อง SQL → กด **Run** → ต้องขึ้น *Success. No rows returned*

### 2) เอารหัสเชื่อมต่อ
1. เมนูซ้ายล่าง ⚙ **Project Settings** → **API** (หรือ **API Keys**)
2. คัดลอก **Project URL** (ลงท้าย `.supabase.co`)
3. คัดลอกคีย์ **anon / publishable** (ห้ามใช้ `service_role` / `secret`)

### 3) เชื่อมกับแอป (เลือกอย่างใดอย่างหนึ่ง)
- **แบบง่าย:** เปิดแอป → วาง URL และ Key ในหน้า "ตั้งค่าการเชื่อมต่อ" → **เชื่อมต่อ** แล้วไปแท็บ **แพทย์/ชื่อ** → **คัดลอกลิงก์ให้น้องๆ** ส่งในกลุ่ม น้องเปิดลิงก์ครั้งเดียวก็ใช้ได้เลย
- **แบบอัตโนมัติทุกเครื่อง:** GitHub → **Settings → Secrets and variables → Actions → New repository secret** สร้าง 2 ตัว: `SUPABASE_URL` และ `SUPABASE_KEY` แล้วไปแท็บ **Actions → อัปเดตแอปอัตโนมัติ → Re-run all jobs** ทุกเครื่องเปิดลิงก์แอปได้เลยโดยไม่ต้องตั้งค่า

## อัปเดตแอป
GitHub → กดไฟล์ → ✏️ แก้ (หรือ **Add file → Upload files** ทับไฟล์เดิม) → **Commit changes** → รอ 2–3 นาที (ดูแท็บ **Actions** ถ้าเป็นเครื่องหมายถูกเขียว = สำเร็จ) → ทุกเครื่องโหลดแอปใหม่เองเมื่อเปิดแอปหรือภายใน 5 นาที

## สำรองข้อมูล
- **อัตโนมัติ:** ทุกสัปดาห์ (อาทิตย์/พุธ) GitHub สำรองข้อมูลเก็บไว้ที่แท็บ **Actions → รอบล่าสุด → Artifacts** (เก็บ 90 วัน เฉพาะเจ้าของ repo) การรันนี้ช่วยให้ Supabase ฟรีไม่ถูกพักโปรเจกต์ด้วย
- **ด้วยมือ:** ในแอป แท็บ **แพทย์/ชื่อ** → **ดาวน์โหลดไฟล์สำรอง** (เก็บลง OneDrive เองได้) และ **นำเข้าไฟล์สำรอง** เพื่อกู้คืน

## ข้อควรรู้
- Supabase ฟรีจะพักโปรเจกต์ถ้าไม่มีการใช้งานเกิน 7 วัน ถ้าแอปขึ้นว่าฐานข้อมูลไม่ตอบ ให้เข้า supabase.com แล้วกด **Restore project**
- Key แบบ anon เปิดเผยอยู่ในลิงก์แอปได้ตามแบบของ Supabase แต่ส่งลิงก์เฉพาะในกลุ่มทีม
- ข้อมูลในแอปไม่ควรมีชื่อ/HN ผู้ป่วย
